# Kitchen Platform

Веб-платформа R&D кухни: справочник ингредиентов, расчёт себестоимости и
маржи, технологические карты, расчётка для коммерческого отдела, мониторинг
конкурентов, слепые дегустации.

Приходит на смену трём Telegram-ботам. Google-таблица при этом **остаётся**
рабочей площадкой шефа — платформа встаёт под неё, а не вместо неё.

## Состояние

Фаза 2 — веб только на чтение: вход, справочник ингредиентов, блюда,
карточка блюда, сверка справочника. Выложено на `art.karppacho.ru`.
Подробности и доказательства — в [роадмапе](docs/ROADMAP.md).

## Как устроена разработка

- **Стек:** FastAPI, SQLAlchemy 2 и Alembic на Postgres (Supabase на своём
  сервере); React 18, TypeScript и TanStack Query; выкладка — docker compose
  за nginx с TLS.
- **Код пишется с Claude Code.** Правила проекта — в [CLAUDE.md](CLAUDE.md),
  профильные ревьюеры — в [.claude/agents/](.claude/agents/): инварианты
  себестоимости, миграции, контракт с Google-таблицами, эксплуатационная
  безопасность. Крупная работа идёт по спеке и плану из
  [docs/superpowers/](docs/superpowers/): сначала тесты, затем отдельное ревью
  каждой задачи.
- **CI — 8 проверок на каждый PR:** ruff, mypy strict, слои (import-linter),
  тесты (офлайн и интеграция на Postgres 16, порог покрытия 85 %), секреты
  (gitleaks), зависимости (lock-файл и известные уязвимости), фронтенд (типы,
  линт, тесты, сборка), образ nginx (живая проверка заголовков и маршрутов).
- **`main` защищена:** слияние только через PR с зелёным CI.
- **Эталон:** себестоимость 130 блюд сверяется с расчётом старого бота
  (`backend/scripts/verify_golden.py`, эталон —
  `backend/tests/golden/dishes_uc.json`); совпадают 129, одно расхождение
  названо. Эталон под код не подгоняют.

## Быстрый старт

```bash
cd backend && uv sync --all-extras --dev
cd .. && make check
```

## Фронтенд в разработке

Нужен Node 22.4 или новее.

```bash
cd frontend && npm ci && npm run dev   # http://localhost:5173
```

Vite проксирует `/api` на `127.0.0.1:8080`. Бэкенд туда поднимается
локально — нужен `.env` с базой и Supabase:

```bash
cd backend && uv run uvicorn kitchen.web.app:app --port 8080
```

Либо пробрасывается боевой по SSH: `ssh -N -L 8080:127.0.0.1:8080 <user>@<сервер>`.
Ручки только на чтение, но данные настоящие.

Куки входа идут с флагом `Secure` (`SESSION_COOKIE_SECURE=true`, как в
образце). Chrome и Firefox считают `http://localhost` безопасным контекстом
и такую куку принимают; Safari — нет. Для него в локальном `.env` бэкенда
нужно `false`, и только там.
