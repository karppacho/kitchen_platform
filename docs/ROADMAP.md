  контейнера как `PGPORT`. Привязка только оверлеем и только с `!override` —
  списки портов при слиянии дописываются, а не заменяются.

## Фаза 1 — склейка справочника и эквивалентность расчёта ✅

Главная работа проекта: справочник ингредиентов расколот надвое, и
калькулятор не видит того, что оформили повара.

**Замер на живых данных (09.09.2026):** 107 карточек, 91 склеилась
однозначно, **16 требуют решения человека** — 5 тёзок, 4 кандидата,
7 без пары вовсе.

- [x] Схема БД: 8 таблиц, первая миграция, обратимость проверена на боевом Postgres
- [x] Сопоставление имён: точное совпадение решает только если оно одно
- [x] Пакетное чтение: два обращения на таблицу вместо одного на лист.
      Проверено двумя прогонами отчёта подряд без 429
- [x] Импорт листов в БД + запись прогона в `sync_runs`.
      Перенесено: 130 ингредиентов, 28 упаковок, 15 способов, 130 блюд,
      701 строка ТТК, 101 карточка
- [x] Перенос калькулятора себестоимости из `kitchen_bot`
- [x] **Приёмка: 129 из 130 блюд совпадают с эталоном**, одно расхождение
      названо в `KNOWN_DIVERGENCES`. Прогон: `scripts/verify_golden.py`,
      код возврата 0
- [ ] Экран ручной сверки: слева ING, справа карточки, решение за шефом.
      **Переезжает в фазу 2** — ему нужен интерфейс
- [ ] Поллинг раз в 5 минут (пакетное чтение уже есть, нужен воркер)

**Найдено по дороге.** В листе `ING` строки 132–169 не имеют id — 38 строк.
Отсюда расхождение «168 строк в листе, 130 ингредиентов». Импорт их
пропускает и называет поимённо; что это за блок, стоит посмотреть шефу.

**Открытый вопрос.** В таблице карточек семь листов, а не один:
`Фритюрные продукты`, `Топпинги`, `Овощи`, `Соусы`, `Заявки`. Бот пишет
только в `Лист1`, остальные ведут руками — там могут быть ещё ингредиенты,
и тогда «сирот» окажется больше семи.

## Как вести этот файл

Пункт переезжает в «сделано» только вместе со строкой доказательства.
Найденное по дороге — в раздел фазы, а разбор инцидента — в журнал в
[CLAUDE.md](../CLAUDE.md). Роадмап отвечает на вопрос «что дальше»,
журнал — на вопрос «почему так сделано».
