# MCP-сервер платформы: ИИ по подписке пользователя — спека

Дата: 02.11.2026. Статус: черновик, ждёт согласия Александра (меняет правило 4 `CLAUDE.md`).
Основание: решение 02.11.2026 — функции, которые сейчас делает ИИ через платный API (polza.ai), перенести на MCP: шеф и повара подключают платформу в Claude или ChatGPT и работают на своей подписке. Разведка — ветка `mcp-razvedka` (прототип 97c6c4f), отчёт в её `.superpowers/sdd/2026-11-02-mcp-razvedka/report.md`.

## Решения (02.11.2026, закон для плана)
1. **Удалённый MCP** на нашем домене: `https://<домен>/mcp`, транспорт Streamable HTTP (stateless). Наружу по-прежнему только 443.
2. **Свой OAuth 2.1** в бэкенде на интерфейсах SDK `mcp` (вариант «a» разведки): DCR, PKCE, refresh с ротацией, отзыв. Вход на странице `/authorize` — тем же логином и паролем, что на сайте (GoTrue по паролю, как `POST /api/auth/login`), затем экран согласия. Supabase OAuth server не используем (бета, обновление GoTrue задевает вход всех).
3. **Claude и ChatGPT — наравне.** Инструменты записи — без `readOnlyHint` (клиент спросит подтверждение); инструменты чтения — с `readOnlyHint`. Если на тарифе ChatGPT запись недоступна, черновик всё равно доступен по ссылке на веб-мастер.
4. **Роли — как на сайте.** Повар: карточки и справочник **без цен** (цены отсекаются в данных, а не в описании инструмента). Шеф, коммерция, разработчик: всё чтение, включая цены и блюда.
5. **polza.ai остаётся** запасной кнопкой «Распознать» в веб-мастере (бюджет можно поставить 0). Платформа сама модели по подписке не вызывает и не автоматизирует.
6. **Веб-чат не строим** — его заменяет MCP.

## Неизменные правила
- Правило 3: все числа считает код. Инструменты отдают посчитанное с единицами; описание инструмента просит не пересчитывать; «а если» — только инструментом `poschitat_sostav`.
- Правило 1: новых путей записи в таблицы нет. Запись — только существующими писателями через слой `cards/*` (черновик → отправка в веб-мастере; `eto_on` пишет только в базу).
- Правило 5: деньги и веса — `Decimal`; в ответах инструментов — строками без потери точности (`format(d, "f")`), пусто — `null`.
- Слои: `kitchen.mcp` — транспорт, отдельный слой между `web | worker` и `cards` (`web.app` его монтирует). Роли и проверка пользователя выносятся из `web/auth.py` ниже (общие для `web` и `mcp`).

## Безопасность
- `/mcp` без действительного токена — 401 с `WWW-Authenticate`; флаг `MCP_ENABLED` по умолчанию выключен.
- Токены, коды и refresh хранятся только хешами; срок кода — 10 минут, access — 1 ч, refresh — с ротацией; отзыв.
- `/authorize`: CSRF, ограничение частоты (nginx, как у `/api/auth/`), белый список `redirect_uri` (callback claude.ai и claude.com, callback ChatGPT, loopback для Claude Code); открытый DCR, но доступ — только после входа и согласия; уборка незавершённых клиентов.
- DNS rebinding: `TransportSecuritySettings(allowed_hosts=[домен])`.
- Журнал вызовов: кто, инструмент, отпечаток аргументов, исход — без секретов и без цен.
- nginx: `/mcp`, `/authorize`, `/token`, `/register`, `/revoke`, `/.well-known/oauth-*` — только 443, свой предел частоты и размера тела, таймаут стрима. Белый список IP Anthropic — по решению Александра.

## Вне этой части
Запись в ING через MCP («Добавить в справочник»), расчётка, дегустации, конкуренты — инструментами по мере появления функций. Живая проверка коннектора в claude.ai, на телефоне и в ChatGPT — после возвращения сервера.
