# Как здесь работать

## Установка

```bash
cd backend
uv sync --all-extras --dev
cd .. && pre-commit install
```

Нужны: Python 3.12+, [uv](https://docs.astral.sh/uv/), Docker (для Postgres
в интеграционных тестах).

## Проверки

```bash
make check      # всё, что блокирует PR: ruff + mypy + слои + офлайн-тесты
make format     # починить то, что чинится автоматически
make test-int   # тесты, которым нужен поднятый Postgres
make test-live  # живые тесты: настоящие Sheets, нужны креды
```

**На Windows `make` обычно не установлен.** Команды внутри целей однострочные,
их можно выполнять как есть — открой `Makefile` и скопируй нужную. Например
вместо `make test`:

```bash
cd backend && uv run pytest
```

## Ветки и PR

Работаем в ветках, сливаем через PR с зелёным CI. `main` защищена.

Блокирующий CI обязан укладываться в пять минут. Если добавляешь медленную
проверку — ей место в ночном прогоне или в ручном запуске, а не в PR.
Проверки защищают, только пока их терпят.

## Тесты

Маркеры разделяют наборы по тому, что им нужно:

| Маркер | Что требуется | Когда идёт |
|---|---|---|
| без маркера | ничего | всегда, в том числе в PR |
| `integration` | Postgres | CI |
| `live` | креды Google, настоящая таблица | вручную |
| `e2e` | браузер | ночной прогон |
| `llm` | платная модель | вручную |

По умолчанию `pytest` гоняет только офлайн-набор.

**Пропуск делается через `pytest.skip`, а не через ранний `return`.**
В `kitchen_bot` живые тесты при отсутствии кредов возвращали управление
молча, и прогон выглядел зелёным, хотя четыре теста не выполнились.

## Ревью

Общий проход делают встроенные `/code-review` и `/security-review`.
Специфику проекта закрывают агенты в `.claude/agents/`:

| Агент | Когда звать |
|---|---|
| `domain-guard` | правки в расчётах, моделях, золотых файлах |
| `sheets-guard` | всё, что трогает обмен с Google Sheets |
| `migration-guard` | новые ревизии Alembic |
| `infra-auditor` | `infra/`, `deploy.sh`, настройки, перед публикацией наружу |

## Деплой

Только скриптом и только на сервере:

```bash
./scripts/deploy.sh
```

Он снимает дамп базы до миграций, перезапускает контейнеры, проверяет, что
`/healthz` отдаёт ожидаемый коммит, и откатывается при провале. Руками
`git pull` на сервере не делаем — на этом уже обжигались.
